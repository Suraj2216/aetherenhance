# AetherEnhance

AetherEnhance is an AI-powered image enhancement model that improves photo quality using deep learning techniques. It supports features like denoising, super-resolution, and color enhancement.

## Features

- Image upscaling (2x, 4x)
- Denoising and sharpening
- Auto color and light correction

## Usage

```bash
python model.py --input input.jpg --output output.jpg
```

## Requirements

Install dependencies

```bash
pip install -r requirements.txt
```

## Model

Trained on high-resolution image datasets. Pretrained weights can be found [here](httpshuggingface.cosuraj2216aetherenhance-model).
